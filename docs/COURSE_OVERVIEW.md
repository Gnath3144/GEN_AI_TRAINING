## 2. Course Vision & Focus
This 10-day intensive curriculum prepares software engineers and data practitioners to build real-world, production-ready Generative AI systems. The learning journey is strictly focused on:

- **Python-based LLM application development**: Structuring clean services, managing environments, and handling errors.
- **LLM APIs and prompt engineering**: System framing, parameter controls, few-shot patterns, and token economics.
- **Structured outputs and tool calling**: Enforcing Pydantic schemas and executing controlled Python functions.
- **Embeddings, semantic search, and RAG**: Document chunking, ChromaDB vector stores, and citation-grounded answering.
- **Open-source models and multimodal AI**: Self-hosted models via Ollama and vision-language diagnostics.
- **LLM evaluation, reliability, and safety**: Mitigating prompt injection, PII sanitization, caching, and quantitative RAG metrics.
- **Agents and workflow orchestration**: Implementing bounded ReAct (Reason + Act) autonomous loops.
- **Building and demonstrating working applications**: Delivering web dashboards and an end-to-end Capstone project.

---

## 3. Pedagogical Rhythm
Each session follows a 4-part classroom rhythm:
1. **Concept Briefing (30-45 mins)**: Core theoretical foundations, failure modes, and architectural trade-offs.
2. **Instructor Live Demonstration (30-45 mins)**: Step-by-step walkthrough of the day's demo notebook or Python application.
3. **Learner Hands-on Lab (60-90 mins)**: Practical exercises where students implement solutions against clear validation criteria.
4. **Debrief & Solution Analysis (30 mins)**: Code review, edge cases, and industry best practices.

---

## 4. Dual-Track Architecture
To ensure accessibility regardless of corporate firewall restrictions or paid API budgets:
- **Track A (Zero-Cost Local Track)**: Uses Ollama (`llama3.2:1b`, `llama3.2:3b`), local sentence transformers, and ChromaDB. Fully functional offline.
- **Track B (Cloud Frontier Track)**: Uses OpenAI (GPT-4o / GPT-4o-mini), Google Gemini, or Anthropic Claude for high-throughput enterprise scale.

All code examples include automated fallback detection.
